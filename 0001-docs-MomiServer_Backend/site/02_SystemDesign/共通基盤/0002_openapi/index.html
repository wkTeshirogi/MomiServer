    APIドキュメント公開¶

    概要¶

    OpenAPI定義とSwagger UIを公開し、API仕様確認を可能にする。

    公開パス¶

    項目 パス
    OpenAPI JSON /v3/api-docs
    Swagger UI /swagger-ui.html

    認証¶

    OpenAPI全体にはBearer認証スキームを設定する。ただし認証APIはセキュリティ設定上、認証不要で利用できる。
