# ログ設計

## ログレベル

| 対象 | レベル |
| --- | --- |
| root | INFO |
| アプリケーション独自領域 | DEBUG |
| Spring Security | DEBUG |
| Hibernate SQL | WARN |
| Flyway | DEBUG |

## エラーログ

DB処理エラーおよび予期しないエラーでは、HTTPメソッド、リクエストURI、例外内容をエラーレベルで記録する。

## 方針

- クライアントへ内部例外情報を返却しない。
- エラー原因調査に必要な情報はサーバログへ記録する。
- 認証・認可失敗は共通エラー応答として返却する。

APIアクセス履歴の永続化、検索、保持期間については、
[APIアクセスログ基本設計](./0004_api_access_log.md)を参照する。
