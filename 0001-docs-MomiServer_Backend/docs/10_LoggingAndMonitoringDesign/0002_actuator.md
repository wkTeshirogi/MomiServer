# Actuator監視設計

## 公開エンドポイント

| No | エンドポイント | 用途 |
| --- | --- | --- |
| 1 | health | ヘルスチェック |
| 2 | info | アプリケーション情報 |
| 3 | metrics | メトリクス |
| 4 | prometheus | Prometheus連携 |
| 5 | env | 環境情報 |
| 6 | loggers | ログレベル確認・変更 |

## ヘルス詳細

ヘルスチェック詳細は認証済みユーザー向けに表示する。

## 利用方針

- 死活監視はhealthを利用する。
- メトリクス収集はmetricsまたはprometheusを利用する。
- 本番環境ではenvやloggersの公開範囲を運用ポリシーに合わせて制限する。
