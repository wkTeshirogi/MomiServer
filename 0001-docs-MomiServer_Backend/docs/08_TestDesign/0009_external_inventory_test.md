### 発行・無効化の通知表示先

利用者指定の通知表示先へ変更後、専用16件と既存43件の全59件が成功した。
発行の通知はモーダル内、無効化はページ上部という境界を次の観点で確認した。

| 観点 | 結果 |
| --- | --- |
| 発行成功 | 原文表示モーダル内に成功NotificationBannerが1個表示され、閉じるとページに残らない |
| 成功通知の非表示 | 通知だけを閉じても原文は表示され、秘密値を勝手に破棄しない |
| 入力・発行失敗 | 発行モーダル上部に1個だけ表示し、ページへ重複表示しない。入力を保持 |
| 無効化成功・失敗 | 確認モーダルを閉じ、ページ上部にだけ表示 |
| 通知混在防止 | 発行失敗後の無効化確認、無効化結果後の発行モーダルに前操作の通知を表示しない |
