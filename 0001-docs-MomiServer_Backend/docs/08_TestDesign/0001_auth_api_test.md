# 認証APIテスト

## 対象

| No | API | 観点 |
| --- | --- | --- |
| 1 | ユーザー登録 | 正常登録、メール重複、入力不正 |
| 2 | ログイン | 認証成功、認証失敗、入力不正 |
| 3 | トークン更新 | 正常更新、トークン不正、期限切れ |
| 4 | ユーザー設定変更 | 入力形式、未実装状態の確認 |

## 確認項目

- 正常時にHTTP 200を返すこと。
- トークンレスポンスにアクセストークン、リフレッシュトークン、有効期限秒数が含まれること。
- 入力不正時に共通エラーレスポンスを返すこと。
- パスワードは平文保存されないこと。
