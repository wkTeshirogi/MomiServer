# JWT認証設計

## 認証方式

| 項目 | 内容 |
| --- | --- |
| 方式 | JWT Bearer認証 |
| ヘッダー | `Authorization: Bearer {accessToken}` |
| セッション | ステートレス |
| アクセストークン有効期限 | 86400秒 |
| リフレッシュトークン有効期限 | 86400秒 |
| 発行者 | SmartHomeWebServerBackend |

## アクセストークン

| 項目 | 内容 |
| --- | --- |
| 用途 | APIアクセス認証 |
| 識別子 | メールアドレス |
| 含める情報 | トークン種別、権限 |

## リフレッシュトークン

| 項目 | 内容 |
| --- | --- |
| 用途 | トークン再発行 |
| 識別子 | メールアドレス |
| 検証 | 署名、有効期限、トークン種別 |
