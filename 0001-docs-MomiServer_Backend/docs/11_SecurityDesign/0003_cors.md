# CORS設計

## 設定

| 項目 | 内容 |
| --- | --- |
| 許可オリジン | `app.cors.allowed-origins` の値 |
| 環境変数 | `APP_CORS_ALLOWED_ORIGINS` |
| 既定値 | `http://localhost:5173` |
| 許可メソッド | GET、POST、PUT、DELETE、OPTIONS |
| 許可ヘッダー | すべて |
| 認証情報 | 許可 |

## 方針

- フロントエンド開発サーバからのアクセスを許可する。
- 本番環境では公開ドメインに合わせて `APP_CORS_ALLOWED_ORIGINS` を設定する。
- 複数オリジンを許可する場合は、環境変数へカンマ区切りで指定する。
- JWTを利用する画面操作APIでは認証情報を許可するため、ワイルドカードオリジンは使用しない。
