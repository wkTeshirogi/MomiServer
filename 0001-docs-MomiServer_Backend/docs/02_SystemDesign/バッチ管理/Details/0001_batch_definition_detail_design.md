# バッチ定義管理 詳細設計

## 目的

バッチ処理の実行方法、実行条件、ログ、通知に関する定義情報を管理する。

## 対象操作

| 操作 | 内容 |
| --- | --- |
| 一覧参照 | 登録済みのバッチ定義を一覧で参照する。 |
| 詳細参照 | バッチ定義IDを指定して詳細を参照する。 |
| 登録 | 新しいバッチ定義を登録する。 |
| 更新 | 既存のバッチ定義を更新する。 |

## 管理項目

| 項目 | 内容 | 必須 |
| --- | --- | --- |
| batch_name | バッチの内部識別名。 | 必須 |
| view_name | 画面表示名。 | 必須 |
| category | バッチ分類。 | 必須 |
| execution_type | 実行種別。 | 必須 |
| execution_command | 実行コマンド。 | 必須 |
| working_directory | 作業ディレクトリ。 | 任意 |
| timeout_seconds | タイムアウト秒数。 | 任意 |
| max_retry_count | 最大リトライ回数。 | 任意 |
| retry_interval_seconds | リトライ間隔秒数。 | 任意 |
| allow_parallel_execution | 並列実行可否。 | 任意 |
| log_retention_date | ログ保持期限。 | 任意 |
| log_path | ログ出力先。 | 必須 |
| success_notification | 成功時通知可否。 | 任意 |
| failure_notification | 失敗時通知可否。 | 任意 |
| enabled | 有効状態。 | 任意 |

## 登録・更新判定

| 条件 | 処理 |
| --- | --- |
| ID未指定 | 新規登録する。 |
| IDが0以下 | 新規登録する。 |
| ID指定あり | 既存定義を更新する。 |
| ID指定ありで対象なし | エラーとする。 |

## 入力チェック

| チェック | 内容 |
| --- | --- |
| 必須チェック | バッチ名、表示名、カテゴリ、実行種別、実行コマンド、ログ出力先を必須とする。 |
| 一意チェック | バッチ名は重複しないこと。 |
| 数値範囲 | タイムアウト秒数、最大リトライ回数、リトライ間隔秒数は0以上とする。 |
| 実行種別 | 許可された実行種別のみ登録できること。 |

## 出力

登録・更新後は、保存後のバッチ定義詳細を返却する。

## 関連データ

| データ | 内容 |
| --- | --- |
| バッチ定義パラメータ | バッチ定義に紐づく実行時パラメータ。 |
| バッチスケジュール | バッチ定義を参照する実行スケジュール。 |
| 実行要求 | バッチ定義から作成される実行単位。 |
