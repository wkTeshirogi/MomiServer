# ユーザーマスタ参照

## 概要

管理者向けにユーザー一覧とユーザー詳細を参照する機能を提供する。

## 対象API

| No | API | 概要 |
| --- | --- | --- |
| 1 | `/api/master/user/list` | ユーザー一覧取得 |
| 2 | `/api/master/user/detail` | ユーザー詳細取得 |

## 一覧取得

- ユーザーをID昇順で取得する。
- 0件の場合は空配列を返却する。
- パスワードはレスポンスに含めない。

## 詳細取得

- ユーザーIDを指定して1件取得する。
- 対象ユーザーが存在しない場合は404を返却する。
- パスワードはレスポンスに含めない。

## 権限

管理者権限を持つユーザーのみ利用できる。
