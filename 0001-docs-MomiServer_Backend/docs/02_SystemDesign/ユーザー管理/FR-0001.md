# FR-0001 | ユーザーの作成・更新・削除

## 概要

ユーザー登録APIによりユーザーを作成する。ユーザー設定変更APIは定義されているが、現時点では更新処理は未実装とする。削除APIは現時点では未実装とする。

## 対象API

| メソッド | パス | 内容 |
| --- | --- | --- |
| POST | `/api/auth/register` | ユーザー登録 |
| POST | `/api/auth/settings` | ユーザー設定変更 |

## ユーザー登録処理

1. メールアドレスとパスワードを受け取る。
2. メールアドレスの重複を確認する。
3. パスワードをハッシュ化する。
4. ユーザー情報を保存する。
5. 登録後に利用するトークンを返却する。

## ユーザー設定変更処理

現時点ではリクエスト形式のみ定義されている。更新処理、レスポンスボディ、レスポンスステータスの明示指定は今後実装する。

## データ項目

| 項目 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| email | string | 必須 | メールアドレス |
| password | string | 必須 | パスワード |
| role | string | 任意 | 権限 |

## DB

ユーザー情報は `m_users` で管理する。
削除扱いはマスタ共通方針に従い、ユーザーのステータス更新で表現する。
削除専用フラグや物理削除では管理しない。

## 備考

削除APIは現時点では提供しない。
削除機能を実装する場合も、全てのマスタと同様に、物理削除や削除専用フラグの更新ではなく、ユーザーのステータスを削除扱いの状態へ更新する。
