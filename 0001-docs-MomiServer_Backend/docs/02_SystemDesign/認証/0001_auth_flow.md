# 認証フロー

## 概要

ユーザー登録、ログイン、ユーザー設定変更を提供する。

## 対象API

| No | API | 概要 |
| --- | --- | --- |
| 1 | `/api/auth/register` | ユーザー登録とトークン発行 |
| 2 | `/api/auth/login` | 認証とトークン発行 |
| 3 | `/api/auth/settings` | ユーザー設定変更 |

## ユーザー登録

1. メールアドレスとパスワードを受け取る。
2. メールアドレスの重複を確認する。
3. パスワードをハッシュ化する。
4. ユーザーを登録する。
5. トークンを発行して返却する。

## ログイン

1. メールアドレスとパスワードを受け取る。
2. 認証を行う。
3. ユーザー情報を取得する。
4. トークンを発行して返却する。

## 入力制約

| 項目 | 制約 |
| --- | --- |
| email | 必須、メールアドレス形式 |
| password | 必須、8文字以上 |
