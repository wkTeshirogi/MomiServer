# 認証セッション管理

## 概要

ログイン時にアクセストークンとリフレッシュトークンを発行し、リフレッシュトークンに紐づくセッションをサーバ側で管理する。

## セッション生成

1. 認証成功時にセッションIDを生成する。
2. セッションIDをアクセストークンとリフレッシュトークンに含める。
3. リフレッシュトークンはハッシュ化して保存する。
4. セッションには利用者メールアドレス、有効期限、最終利用日時、失効状態を保持する。

## トークン更新

1. リフレッシュトークンの署名、有効期限、用途を検証する。
2. トークンから利用者とセッションIDを特定する。
3. 保存済みセッションが有効であり、保存済みハッシュと一致することを確認する。
4. 新しいアクセストークンとリフレッシュトークンを発行する。
5. 同一セッションのリフレッシュトークンハッシュと有効期限を更新する。

## ログアウト

アクセストークンまたはリフレッシュトークンからセッションIDを取得し、該当セッションを失効状態にする。無効なトークンが指定された場合もログアウト処理は冪等に扱う。

## セキュリティ方針

- リフレッシュトークンの平文は保存しない。
- セッションが失効済み、期限切れ、または利用者不一致の場合は更新を拒否する。
- アクセストークン単体ではリフレッシュトークンの再発行を許可しない。
