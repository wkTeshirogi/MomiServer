# トークン管理

## 概要

JWTを利用してAPIアクセス用トークンと再発行用トークンを管理する。

## トークン種別

| 種別 | 用途 | 有効期限 |
| --- | --- | --- |
| アクセストークン | APIアクセス | 86400秒 |
| リフレッシュトークン | トークン再発行 | 86400秒 |

## 再発行処理

1. リフレッシュトークンを受け取る。
2. 署名、期限、トークン種別を検証する。
3. ユーザーを取得する。
4. 新しいトークンペアを発行する。

## 認証フィルタ

認証が必要なAPIではBearerトークンを検証し、妥当な場合に認証済みユーザーとして扱う。
