# デバイスマスタ参照

## 概要

管理者向けにデバイス一覧とデバイス詳細を参照する機能を提供する。

## 対象API

| No | API | 概要 |
| --- | --- | --- |
| 1 | `/api/master/device/list` | デバイス一覧取得 |
| 2 | `/api/master/device/detail` | デバイス詳細取得 |

## 一覧取得

- デバイスを全件取得する。
- 0件の場合は空配列を返却する。
- 並び順、ページング、絞り込み、最大取得件数は定義しない。

## 詳細取得

- デバイスIDを指定して1件取得する。
- 対象デバイスが存在しない場合は404を返却する。

## 主な項目

| 項目 | 内容 |
| --- | --- |
| devicename | デバイス名 |
| address | IPアドレス |
| location | 設置場所 |
| mqtt_client_id | MQTTクライアントID |
| status | 状態 |
