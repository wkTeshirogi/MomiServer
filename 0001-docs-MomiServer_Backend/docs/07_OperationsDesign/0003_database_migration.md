# DBマイグレーション運用

## 基本方針

DBスキーマはマイグレーションで管理する。

| 項目 | 内容 |
| --- | --- |
| マイグレーション | 有効 |
| 既存DBの取り込み | baseline-on-migrate有効 |
| 検証 | validate-on-migrate無効 |
| JPA DDL | validate |

## 運用手順

1. マイグレーションファイルを追加する。
2. アプリケーション起動時にマイグレーションを適用する。
3. jOOQを利用する場合はスキーマ変更後にコード生成を行う。

## 注意事項

- DB定義とAPIレスポンス項目の差分は、マイグレーション追加時に確認する。
- 開発中にマイグレーション内容を変更した場合、既存DBとの差分に注意する。
