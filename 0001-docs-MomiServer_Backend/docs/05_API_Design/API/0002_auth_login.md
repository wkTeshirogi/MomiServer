# ログイン API

## 基本情報

| 項目 | 内容 |
| --- | --- |
| API ID | API-0002 |
| 分類 | 認証 |
| メソッド | POST |
| パス | `/api/auth/login` |
| 認証 | 不要 |
| 権限 | なし |
| 正常ステータス | HTTP 200 |

## 概要

メールアドレスとパスワードを検証し、認証成功時にトークンを返却する。

## 処理概要

1. メールアドレスとパスワードを認証する。
2. メールアドレスに一致するユーザーを取得する。
3. アクセストークンとリフレッシュトークンを生成して返却する。

## リクエストボディ

| 項目 | 型 | 必須 | 制約 | 説明 |
| --- | --- | --- | --- | --- |
| email | string | 必須 | メールアドレス形式 | ログインID |
| password | string | 必須 | 8文字以上 | ログインパスワード |

## レスポンス

| 項目 | 型 | 説明 |
| --- | --- | --- |
| accessToken | string | アクセストークン |
| refreshToken | string | リフレッシュトークン |
| expiresnIn | number | アクセストークン有効期限秒数。項目名は現行API仕様に合わせる |

## 主なエラー

| HTTPステータス | code | 説明 |
| --- | --- | --- |
| 400 | `VALIDATION_ERROR` | 入力値の形式不正 |
| 400 | `MALFORMED_REQUEST` | リクエストボディ読取不可 |
| 401 | `AUTHENTICATION_FAILED` | メールアドレスまたはパスワード不一致 |
| 500 | `DATABASE_ERROR` | DB処理エラー |
| 500 | `INTERNAL_SERVER_ERROR` | 予期しないエラー |
