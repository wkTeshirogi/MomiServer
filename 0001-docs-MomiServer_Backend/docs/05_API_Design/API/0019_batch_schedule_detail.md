# バッチスケジュール詳細取得 API

## 基本情報

| 項目 | 内容 |
| --- | --- |
| API ID | API-0019 |
| 分類 | バッチスケジュールマスタ |
| メソッド | POST |
| パス | `/api/master/batch/schedule/detail` |
| 認証 | 必要 |
| 権限 | 管理者 |
| 正常ステータス | HTTP 200 |

## 概要

指定されたバッチスケジュールIDの詳細情報を取得する。

## リクエストパラメータ

| 項目 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| id | number | 必須 | バッチスケジュールID |

## レスポンス

バッチスケジュール一覧取得APIの1要素と同じ。
