# ログアウト API

## 基本情報

| 項目 | 内容 |
| --- | --- |
| API ID | API-0011 |
| 分類 | 認証 |
| メソッド | POST |
| パス | `/api/auth/logout` |
| 認証 | 任意 |
| 正常ステータス | HTTP 204 |

## 概要

アクセストークンまたはリフレッシュトークンに紐づく認証セッションを失効する。

## リクエストヘッダー

| 項目 | 必須 | 説明 |
| --- | --- | --- |
| Authorization | 任意 | `Bearer {accessToken}` |

## リクエストボディ

| 項目 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| refreshToken | string | 任意 | 失効対象のリフレッシュトークン |

## レスポンス

レスポンスボディなし。

## 主なエラー

| HTTPステータス | code | 説明 |
| --- | --- | --- |
| 500 | `INTERNAL_SERVER_ERROR` | 予期しないエラー |
