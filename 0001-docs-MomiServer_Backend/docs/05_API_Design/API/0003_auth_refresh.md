# トークン更新 API

## 基本情報

| 項目 | 内容 |
| --- | --- |
| API ID | API-0003 |
| 分類 | 認証 |
| メソッド | POST |
| パス | `/api/auth/refresh` |
| 認証 | 不要 |
| 権限 | なし |
| 正常ステータス | HTTP 200 |

## 概要

リフレッシュトークンを検証し、新しいアクセストークンとリフレッシュトークンを発行する。

## 処理概要

1. リフレッシュトークンの署名、有効期限、用途を検証する。
2. トークンから利用者とセッションIDを特定する。
3. サーバ側セッションが有効であり、保存済みトークンハッシュと一致することを確認する。
4. 新しいアクセストークンとリフレッシュトークンを発行する。
5. 同一セッションのリフレッシュトークンハッシュ、有効期限、最終利用日時を更新する。

## リクエストボディ

| 項目 | 型 | 必須 | 制約 | 説明 |
| --- | --- | --- | --- | --- |
| refreshToken | string | 必須 | 空文字不可 | リフレッシュトークン |

## レスポンス

| 項目 | 型 | 説明 |
| --- | --- | --- |
| accessToken | string | 新しいアクセストークン |
| refreshToken | string | 新しいリフレッシュトークン |
| expiresnIn | number | アクセストークン有効期限秒数 |

## 主なエラー

| HTTPステータス | code | 説明 |
| --- | --- | --- |
| 400 | `VALIDATION_ERROR` | リフレッシュトークン未指定 |
| 400 | `MALFORMED_REQUEST` | リクエストボディ読み取り不可 |
| 401 | `INVALID_TOKEN` | トークン不正、期限切れ、失効済み、セッション不一致 |
| 500 | `DATABASE_ERROR` | DB処理エラー |
| 500 | `INTERNAL_SERVER_ERROR` | 予期しないエラー |
