# ユーザー登録 API

## 基本情報

| 項目 | 内容 |
| --- | --- |
| API ID | API-0001 |
| 分類 | 認証 |
| メソッド | POST |
| パス | `/api/auth/register` |
| 認証 | 不要 |
| 権限 | なし |
| 正常ステータス | HTTP 200 |

## 概要

メールアドレスとパスワードでユーザーを登録し、登録後に利用するトークンを返却する。

## 処理概要

1. メールアドレスの重複を確認する。
2. パスワードをハッシュ化してユーザーを登録する。
3. 登録したユーザー向けにアクセストークンとリフレッシュトークンを生成して返却する。

## リクエストボディ

| 項目 | 型 | 必須 | 制約 | 説明 |
| --- | --- | --- | --- | --- |
| email | string | 必須 | メールアドレス形式 | ログインIDとして利用するメールアドレス |
| password | string | 必須 | 8文字以上 | ログインパスワード |

## レスポンス

| 項目 | 型 | 説明 |
| --- | --- | --- |
| accessToken | string | アクセストークン |
| refreshToken | string | リフレッシュトークン |
| expiresnIn | number | アクセストークン有効期限秒数。項目名は現行API仕様に合わせる |

## 主なエラー

| HTTPステータス | code | 説明 |
| --- | --- | --- |
| 400 | `VALIDATION_ERROR` | 入力値の形式不正 |
| 400 | `MALFORMED_REQUEST` | リクエストボディ読取不可 |
| 409 | `DUPLICATE_EMAIL` | メールアドレス重複 |
| 500 | `DATABASE_ERROR` | DB処理エラー |
| 500 | `INTERNAL_SERVER_ERROR` | 予期しないエラー |
