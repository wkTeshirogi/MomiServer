## 運用ルール

- 新しいタスクは、実行可能な単位と具体的な表現で記載する。
- 対応中のタスクには、次に行う作業を記載する。
- 外部要因で進められないタスクは、「保留・待機中」へ移し、理由と再確認時期を残す。
- 完了したタスクは、「完了履歴」へ移し、完了日、結果、根拠資料を記録する。
- 週次進捗の作成時に本一覧を見直し、状態と次のアクションを更新する。
- 完了済み機能を再び未完了として扱う場合は、後退理由または追加要件を明記する。
- 不要になったタスクは、理由を週次記録へ残してから削除または別途アーカイブする。
