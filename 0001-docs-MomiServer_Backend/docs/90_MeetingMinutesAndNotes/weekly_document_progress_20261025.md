# 共通基盤の実装・ドキュメント更新メモ 2026/10/25

## サマリ

BEのページング、FEの通常HTTP取得、BEのトークン用ハッシュを共通化した。
既存のAPI契約、件数上限、ハッシュ形式、画面固有の業務制御を維持した。

## 決定事項

| No | 内容 |
| --- | --- |
| 1 | ページングの検証と先読み・内部ページを共用し、API別の補正・拒否・上限・文言は残す |
| 2 | 通常HTTP取得を共通フックへ移行し、新しい取得・条件変更・アンマウントで古い反映を抑止する |
| 3 | 認証更新、通知ポーリングと既読の連動、WebSocket、原本プレビュー、複数段の業務取得は固有制御を維持する |
| 4 | トークンは従来どおりUTF-8・SHA-256・小文字16進64文字。DB移行・再発行は不要 |
| 5 | パスワード、署名、暗号化、ストリームでのファイルチェックサムは共通トークン処理へ統合しない |

## 作業内容

| 区分 | 内容 |
| --- | --- |
| BEページング | Pagination・PageSliceを追加し、通知・APIログ・実行ログ・外部在庫へ適用 |
| BEハッシュ | TokenHashesを追加。認証セッション・Agent・外部APIの重複処理と定時間比較を集約 |
| FE取得 | 取得レーン、通常データ取得、フォーム固有反映の2段構成。各マスタ・在庫・車両一覧、ログ、状態画面のHTTP、通常フォーム取得等へ適用 |
| FE競合 | 古い成功・失敗・終了処理を抑止。APIキー発行・無効化時に旧一覧を無効化 |
| 保守 | BEのAGENTS・README、FEのREADMEへ共通化方針と対象外を記録 |
| 文書 | 040テンプレートの基本設計3件、090テンプレートの試験設計、130テンプレートの本メモを追加 |

## 確認結果

| 確認項目 | 結果 | 補足 |
| --- | --- | --- |
| BE全JUnit | 690件中687件成功、既存の環境依存3件スキップ、失敗・エラー0 | ページング10ケースとハッシュ8ケースを追加 |
| BEビルド | Flyway38マイグレーション、jOOQ、bootJar、JaCoCo成功 | 独立したPostgreSQL 17とJava 25 |
| BE静的解析 | SpotBugs終了コード0、指摘・解析エラー・不足クラス0 | 解析設定の緩和なし |
| FE単体 | 40件成功 | 取得競合・キャンセル・レーン独立性の5件を追加 |
| FE画面回帰 | Playwright85件成功 | APIキー発行と旧一覧取得の競合を追加。模擬APIを使用 |
| FE静的検証 | build・lint成功 | 追加依存なし。生成APIクライアントは手編集しない |
| 文書検証 | Markdown lint・MkDocs strict build成功 | 既存ナビゲーションと文書リンクを検証 |

## 課題・注意事項

- GitLab上の実パイプライン、SonarQubeサーバー再解析、実BEとFEの結合試験は今回未実施。
- 通常取得の共通化と、通知・認証等の固有制御を混同しない。全APIを汎用CRUDや単一フックへ機械的に置換しない。
- マスタ一覧のサーバー側ページング化は今回の対象外。取得方式・APIの戻り値を変更していない。
