## 追記: 現在日時の取得元を共通Clockへ統一

最新SonarQube結果のjava:S8688の3件は、UserRepositoryの本人設定更新日時が対象だった。

| 区分 | 内容 |

| 絶対時刻 | JWTの発行・ライブラリ検証を同じClockへ統一し、Instantの意味は維持 |
| 経過時間 | System.nanoTimeによる処理時間計測は維持 |
| 保守規約 | BEのAGENTS・READMEにClock注入と単独実行ツールの例外、再起動・既存履歴の注意を追加 |
