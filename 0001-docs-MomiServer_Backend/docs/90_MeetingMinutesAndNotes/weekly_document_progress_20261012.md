## 決定事項

| No | 内容 |
| --- | --- |
| 1 | APIログ画面・APIはADMINとOPERATORが利用可能とする |
| 2 | OPTIONSを除く`/api/**`を記録対象とする |
| 3 | リクエスト・レスポンス本文、認証情報、未加工のクエリ文字列は保存しない |
