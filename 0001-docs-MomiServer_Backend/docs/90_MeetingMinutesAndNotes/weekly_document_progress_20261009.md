進捗で未確定だった「タスク作成・更新・削除」のPhase 1範囲を利用者との確認により確定した。

## 決定事項

| No | 内容 | 反映先 |
| --- | --- | --- |
| 1 | Phase 1のタスクはバッチ管理。人向けの汎用ToDoは対象外 | FR-0019、FR-0020 |
| 2 | 定義更新では作成済み要求を変更せず、新規作成分だけに反映 | FR-0019 |
| 3 | 無効化・未開始取消・実行中の別途取消・終了確認後の論理削除を分離 | FR-0019 |
| 4 | versionによる楽観的ロック、競合409、画面の入力保持・上部エラー | FR-0019 |
| 5 | 定義添付・共通設定は既存合意を維持し、旧転送方式・成果物転送・バックエンド自動回収を後続へ分離 | FR-0019、既存ファイル転送詳細設計 |
