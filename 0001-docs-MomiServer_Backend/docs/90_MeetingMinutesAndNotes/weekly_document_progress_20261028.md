## 決定事項

- 未送信結果を保存日数・再送回数の超過で破棄したり、再送を打ち切ったりしない。
- 計画更新時以外にも適用し、一般の一時ファイルやサーバーログの保持とは分けて扱う。
- 再起動後も未送信結果を保全し、結果再送とバッチ本体の再実行を区別する。
- 通信タイムアウトや再送間隔、他の処理の上限を一括で撤廃する意味ではない。
