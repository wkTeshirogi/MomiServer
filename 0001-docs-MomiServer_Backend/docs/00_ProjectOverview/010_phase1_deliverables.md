# Phase 1 作成物一覧・実装状況

## 目的

Phase 1では、SmartHomeWebServerBackendの基本利用に必要なREST API、認証基盤、基本業務機能、管理画面を作成する。

本書では、現在のソースコードから確認できる実装状況を「実装済み」「一部実装」「未実装」に分類する。

## 判定基準

| 状態 | 判定基準 |
| --- | --- |
| 実装済み | API、画面、DB、共通処理のうち、対象機能を利用するために必要な主要要素が揃っている |
| 一部実装 | 一部のAPI、画面、DB、共通処理はあるが、要件を満たすには不足がある |
| 未実装 | 対象機能を利用するための主要なAPI、画面、DBが確認できない |
