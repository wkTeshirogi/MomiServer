# 外部APIキー管理 画面設計書

## 概要

マスタ一覧の「外部APIキー管理」から`/master/api`へ遷移する。閲覧・発行・無効化はADMINのみ許可する。
`080_ui_design.md`テンプレートを使用した。

## 画面構成

ページヘッダーにタイトル、「利用可能なAPI」「APIキー発行」ボタンを配置する。
処理結果通知と発行済みキー一覧を表示し、発行フォームとAPI一覧はそれぞれモーダルで開く。
API契約と入力制約は[API設計](../05_API_Design/API/0048_external_inventory.md)を参照する。
発行単位・交換手順・スコープの確定仕様は[基本設計](../02_SystemDesign/API%20Gateway/0002_external_api_keys.md)を参照する。

## コンポーネント詳細

| 要素 | 仕様 |
| --- | --- |
| 発行モーダル | 連携先名、在庫参照・数量更新、有効期限、無期限の入力。フッターにキャンセルと発行ボタン |
| API一覧モーダル | 在庫一覧・詳細・数量操作の名称、HTTPメソッド、パス、必要スコープ、認証ヘッダー名 |
| Request body | 本文があるAPIのみ、初期状態で閉じたアコーディオン。Content-Type、項目名・型・必須/任意・制約・JSON例 |
| 一覧上部 | 連携先名検索、再読込、表示範囲・検索結果件数・20/50/100件切替 |
| 一覧 | 名前・識別用先頭部分、権限、状態、期限、最終利用、発行日時・発行者、API一覧と無効化ボタン |
| 一覧下部 | 共通の前へ・次へボタン |
| 発行結果 | 原文の一度限り表示ダイアログ。上部に成功NotificationBanner。コピーして閉じる、閉じる操作 |
| 無効化確認 | キー名・識別用プレフィックス・最終利用日時と再有効化不可を表示。確定中は追加操作を抑止 |

## 状態管理

| State | 型 | 初期値 | 用途 |
| --- | --- | --- | --- |
| キー一覧 | 配列 | 空 | 管理情報のみ保持 |
| 発行モーダル | 真偽値 | false | フォームの開閉。閉じても未送信の入力を保持 |
| 発行エラー | 文字列またはNULL | NULL | モーダル上部で表示する入力・送信エラー |
| API一覧の対象 | 全体、キー情報またはNULL | NULL | 全APIまたは対象キーのスコープで絞ったAPI一覧 |
| 原文 | 文字列またはNULL | NULL | 発行直後の一時表示のみ |
| 有効期限 | 日時 | 発行から1年 | 期限付きキーの有効期限指定 |
| 無期限 | 真偽値 | false | ADMINによる期限なしの明示選択 |
| 処理状態 | 真偽値 | 読込中 | 多重操作の抑止 |
| 通知 | 種別と本文またはNULL | NULL | ページ上部の取得・無効化・コピー結果。発行通知とは分離 |

## 操作フロー

1. 一覧を読み込み、初期20件を表示する。
2. 「APIキー発行」で入力モーダルを開く。発行成功時は一覧へ追加し、入力モーダルを閉じる。
3. 原文の一度限り表示モーダルへ切り替える。閉じると破棄し、一覧・ブラウザ保存領域へ残さない。
4. 無効化は確認後に送信し、成功した行のボタンを非活性化する。

### モーダルの開閉・API一覧

発行モーダルのキャンセル・Esc・閉じる操作では発行要求を送らず、入力を保持して一覧へ戻る。
発行中は入力・発行・キャンセルを無効化し、Esc・背景・閉じる操作でも閉じない。
エラー時は入力モーダルを維持する。成功時は入力と原文のモーダルを同時表示しない。

利用者指定により、この画面の発行通知はページ上部通知の原則から分けて扱う。
入力・発行エラーは発行モーダル上部、発行成功は原文表示モーダル上部のNotificationBannerだけに表示する。
閉じた後は同じ発行通知をページへ残さない。成功通知だけを閉じても、原文表示は閉じない。
無効化の成功・失敗は確認モーダルを閉じた後、ページ上部だけに表示する。
発行用のエラー状態とページ通知を分離し、無効化通知を発行・API一覧・確認モーダルへ流用しない。

ヘッダーの「利用可能なAPI」は外部在庫API全3件を表示する。
各キー行の同アイコンは、そのキーに割り当てられたスコープのAPIだけを表示する。
無効化済み・期限切れのキーは割当内容を確認できるが、利用不可であることを明示する。
キー原文・ハッシュ、管理API、Web・Agent APIはこの一覧に含めない。
APIのパスと権限は既存Controller・API契約に合わせた画面内定義とし、新規APIや外部要求は追加しない。

### Request bodyの表示

APIの下に「Request body」のアコーディオンを表示する。初期状態は閉じ、クリック・Enter・Spaceで開閉する。
モーダルを閉じて開き直した場合は閉じた状態に戻る。本文を持たないGET APIには表示しない。
参照専用キーのAPI一覧にも表示しない。

Phase 1では数量操作APIのみが対象で、`application/json`の項目と送信例を表示する。
項目名・型・必須/任意・入力制約は[API設計](../05_API_Design/API/0048_external_inventory.md)の「数量操作」を正とする。
表示定義はバックエンドDTOと照合し、API変更時は併せて更新する。画面内から実際のAPI送信は行わない。
JSON例の操作IDは説明用の固定値であり、実データ・キー原文を含めない。
長い説明とJSONは折り返し、モーダル本文内で縦スクロールできるようにする。

### 有効期限の追加仕様

無期限は初期状態で選択しない。選択中は期限入力を無効化し、発行時に`expiresAt: null`を送る。
未選択で期限が空、または未来日時でない場合は発行せず、発行モーダル上部へ入力エラーを表示する。
確認モーダルの最終利用日時が未記録の場合は「未利用」と表示する。

2026/10/24に実装済み。初期期限は画面表示時と発行成功後に算出し、ローカル日時で1年後とする。
2月29日から平年への年加算は2月末日へ補正し、送信時にUTCへ変換する。
無期限選択の切替では入力済み期限を保持し、発行成功時は無期限未選択と新しい初期期限へ戻す。
発行失敗時は連携先名・権限・期限・無期限の入力を保持する。

## エラーハンドリング

| 条件 | 表示内容 | 挙動 |
| --- | --- | --- |
| 取得・無効化失敗 | APIエラーまたは共通エラー | ページヘッダー直下へ通知 |
| 発行失敗 | APIエラーまたは共通エラー | 発行モーダル上部だけに表示。入力を保持 |
| 権限未選択・不正期限 | 入力確認メッセージ | 発行モーダル上部だけに表示し、発行しない |
| コピー失敗 | 無効化・再発行の案内 | 原文を閉じる。元キーは勝手に無効化しない |
| USER・OPERATORの直接アクセス | トップへ遷移 | キー一覧APIは呼び出さない |

## アクセシビリティ

入力はラベルと関連付け、権限はチェックボックス、件数はSELECT、処理はアイコン付きボタンとする。
共通モーダルと通知コンポーネントのキーボード・ARIA対応を使用する。

## レスポンシブ対応

| ブレークポイント | 表示方針 |
| --- | --- |
| Mobile | ヘッダー操作を折り返す。モーダル本文は高さ制限付き縦スクロール、APIパスは折り返し |
| Desktop | 一覧比較を優先し、発行とAPI一覧はそれぞれ既存共通モーダル内に表示 |

## 今後の拡張ポイント

車庫などの追加スコープは公開APIの設計確定後に追加し、既存キーの権限は変更しない。
