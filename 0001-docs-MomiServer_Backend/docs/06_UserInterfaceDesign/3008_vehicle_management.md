# 車両管理画面設計書

## 概要

全ユーザーが車両と車検期限を確認し、ADMINおよびOPERATORが車両情報を手動登録・編集する。
期限切れ防止を優先し、危険度の高い車両を一覧上位に表示する。

車両一覧、手動登録、詳細編集、管理終了、車検期限変更履歴は実装済みである。
PDF・画像取込と解析結果確認は共通OCR基盤を用いて実装済みである。期限通知は既存のアラート画面とトップ画面に表示する。
2026/10/26に満了日当日の独立通知と保存成功後の判定を追加実装した。
旧通知の自動解消と車両別通知ON/OFFは追加しない。

## 画面構成

| パス | 画面 | ADMIN | OPERATOR | USER | 実装状態 |
| --- | --- | --- | --- | --- | --- |
| `/vehicles` | 車両一覧 | 閲覧 | 閲覧 | 閲覧 | 実装済み |
| `/vehicles/new` | 車両手動登録 | 利用可 | 利用可 | 利用不可 | 実装済み |
| `/vehicles/import` | PDF・画像取込 | 利用可 | 利用可 | 利用不可 | 実装済み |
| `/vehicles/import/:importId/confirm` | 解析結果確認 | 利用可 | 利用可 | 利用不可 | 実装済み |
| `/vehicles/:vehicleId` | 車両詳細・期限履歴 | 閲覧・編集 | 閲覧・編集 | 閲覧のみ | 実装済み |

## 車両一覧

| 表示順 | 項目 | 仕様 |
| ---: | --- | --- |
| 1 | 車検状態 | `EXPIRED`、`URGENT`、`DUE_SOON`、`UNKNOWN`、`VALID`の順 |
| 2 | 車検有効期間満了日 | 日付を表示する |
| 3 | 残日数 | 基準日から満了日までの日数。期限超過は超過日数を表示する |
| 4 | 表示名 | 利用者が設定した車両名 |
| 5 | 登録番号 | 自動車登録番号または車両番号 |
| 6 | 車名 | 車検証から取得または手動入力した名称 |
| 7 | 型式 | 未取得の場合は「-」を表示する |
| 8 | 最終更新日時 | 車両情報の最終更新日時 |
| 9 | 操作 | 詳細画面へ遷移する |

件数表示、表示件数選択、前後移動は[一覧ページング共通設計](./0001_list_pagination.md)に従う。

## PDF・画像取込

| 要素 | 仕様 |
| --- | --- |
| 対応形式 | PDF、JPEG、JPG、PNG |
| 取込操作 | ドロップまたはファイル選択 |
| 解析方式 | PDFテキスト抽出を優先し、必要な場合はOCR |
| 進行状態 | アップロード中、解析中、確認待ち、失敗を区別する |
| 自動登録 | 行わない。確認画面で登録操作を必要とする |
| 個人情報 | 所有者・使用者の氏名・住所を表示・保存しない |

## 解析結果確認

Desktopでは原本プレビューと入力項目を並べ、Mobileでは原本と入力項目を縦に配置する。

| 項目 | 仕様 |
| --- | --- |
| 原本表示 | 確認中の一時ファイルだけを表示する |
| 読み取り結果 | 車両識別情報と車検期限だけを編集可能項目として表示する |
| 警告 | 必須項目の未抽出を表示し、形式不一致または重複は登録時エラーとして表示する |
| 強調項目 | 車台番号と車検有効期間満了日を必ず確認対象とする |
| 登録 | 必須項目を検証し、登録成功後に原本を削除する |
| キャンセル | 一時ファイルを削除して一覧へ戻る |

## 車両詳細

USERには参照表示だけを提供する。ADMINとOPERATORには編集操作を表示する。
管理終了または削除操作はADMINだけに表示する。

| 分類 | 表示項目 |
| --- | --- |
| 車両識別 | 表示名、登録番号、車台番号、車両識別符号 |
| 車両情報 | 車名、型式、初度登録年月、交付年月日、用途区分 |
| 車検 | 有効期間満了日、状態、残日数。通知はアラート画面で確認する。車両詳細内の最終通知履歴欄は提供しない |
| 履歴 | 期限更新前後、更新者、更新日時 |
| 補足 | 備考、登録日時、更新日時 |

車検期限変更履歴は詳細画面内に表示し、独立した履歴画面への遷移を不要とする。

### 車検更新

登録済み車両の状態・残日数・満了日の横に「車検更新」ボタンを設ける。
ADMIN・OPERATORのみ操作でき、新規登録画面および管理終了車両には表示しない。

| 項目 | 仕様 |
| --- | --- |
| 現在の満了日 | 登録済みの値を読み取り専用表示。通常フォームの未保存値を使用しない |
| 更新年数 | SELECTで1年・2年・3年を選択。開くたびに2年へ初期化 |
| 新しい満了日 | 現在の満了日に選択年数を加えた候補。手動修正可能で必須 |
| 閏日 | 2月29日の更新先が平年の場合は2月28日とする |
| 交付年月日 | 任意。登録済みの値を初期表示。空欄で送信した場合は既存値を維持 |
| 更新する | 現在より後の満了日だけ許可。車検専用APIを呼び出す |
| キャンセル | 更新せず閉じる。再表示時には登録済みの値から初期化 |

更新中は二重送信と閉じる操作を禁止する。エラーはモーダル上部のNotificationBannerへ表示し、入力を保持する。
競合の場合は画面の再読み込みを案内する。成功時はモーダルを閉じ、ページ上部へ通知する。
状態・残日数・期限履歴を更新し、通常フォームの車検関連以外の未保存編集は保持する。
履歴取得だけに失敗した場合は更新成功と履歴取得失敗を分けて表示し、更新の再送を促さない。
保存コミット後に別トランザクションで期限通知を判定する。旧通知の自動解消は追加しない。

### 車両別の期限通知設定（追加対象外）

- 期限通知ON/OFFの車両別入力・表示項目は追加しない。
- 有効・無効の制御は既存の通知全体設定・通知ルート・ユーザー別受信設定を使用する。
- 全車両共通の通知時期を使用し、車両ごとの通知日数・配信先の入力欄は追加しない。
- 車検状態・残日数の表示は現行どおり維持する。

## 通知表示（実装済み）

- 期限通知は既存のアラート画面とトップ画面の通知一覧へ表示する。
- 通知から車両詳細へ遷移できるようにする。
- 通知種別は`vehicle_inspection_expiry`とし、画面上では日本語へ変換する。
- 通知時期・重要度・重複防止は[車検期限管理 基本設計](../02_SystemDesign/車両管理/0001_vehicle_inspection_management.md)を参照する。

### 車検更新後の通知表示（現行を維持）

- 満了日の更新だけを理由に旧通知を自動解消・非表示にしない。
- アラート一覧・トップ通知・未読件数は既存の取得条件と既読・非表示・保持期間の処理を維持する。
- 解消状態の表示や、新しい解消履歴画面・詳細画面内の通知履歴欄は追加しない。

## エラーハンドリング

| 条件 | 表示内容 | 挙動 |
| --- | --- | --- |
| ファイル形式不正 | 対応していないファイル形式です。 | 解析を開始しない |
| 解析失敗 | 車検証を読み取れませんでした。Tesseractの設定を確認するか手動登録を利用してください。 | 原本を削除し、手動登録を案内する |
| 必須項目未取得 | 未入力の必須項目があります。 | 対象入力へフォーカスする |
| 重複候補 | 登録済みの車両に一致する可能性があります。 | 差分確認を表示する |
| 保存失敗 | 車両情報の保存に失敗しました。 | 入力を保持し、ページ上部へ通知する |
| 権限不足 | この操作を実行する権限がありません。 | 編集・取込操作を表示しない |

通常の保存通知は共通ルールに従いページ上部へ表示する。
車検更新モーダル内の失敗は、入力とともに確認できるようモーダル上部へ表示する。

## アクセシビリティ

| 要素 | 対応 |
| --- | --- |
| ファイル入力 | 選択ボタンとドロップ領域へ説明ラベルを付ける |
| 状態 | 色だけでなく状態名と残日数を併記する |
| 解析警告 | 未抽出の項目名を警告内容に含める |
| 原本プレビュー | 非識別表示名を併記し、表示できない場合は代替説明を表示する |
