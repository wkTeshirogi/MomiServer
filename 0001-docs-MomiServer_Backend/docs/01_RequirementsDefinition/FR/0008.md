# 外部向けAPIキー発行

| 項目 | 内容 |
| --- | --- |
| 機能ID | FR-0008 |
| カテゴリ | ユーザー管理 |
| 優先度 | 中 |

## 概要

外部システムが在庫APIを利用するための専用APIキーを発行する機能。Agent専用認証・既存IoT固定キーとは分離する。

## 機能要件

- ADMINのみが連携先名・スコープを指定してAPIキーを発行できること
- 連携システム・用途・環境ごとに別キーを発行し、使い回さない運用とすること
- APIキーの秘密部分は暗号学的乱数256bitで生成すること。管理用UUIDと秘密値を区別すること
- 発行したAPIキーの一覧・発行日時・最終使用日時を参照できること
- 有効期限の画面初期値を発行から1年とし、無期限はADMINが明示的に選択すること
- キー交換は新規発行、連携先切替、旧キー無効化の順で行い、切替中は新旧キーを併用できること
- 発行履歴には操作者・日時・対象キーを記録し、キー原文は含めないこと

## 実装状況

2026/10/24に有効期限の初期値と無期限の明示選択を実装した。
期限付きの空欄・過去日時は発行モーダル上部に入力エラーを表示し、発行要求を送信しない。
発行成功はキー原文を表示するモーダル内のNotificationBannerで通知し、ページ上部へ重複表示しない。
発行成功後は次のキー向けに期限と無期限選択を初期化する。運用・設計の詳細は関連設計を参照する。

## 非機能要件

- APIキーの値はハッシュ化してDBに保存し、発行時のみ平文で表示すること
