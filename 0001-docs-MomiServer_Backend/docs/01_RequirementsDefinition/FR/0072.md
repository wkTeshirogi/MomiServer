# バッチスケジュール管理

| 項目 | 内容 |
| --- | --- |
| 機能ID | FR-0072 |
| カテゴリ | バッチ管理 |
| 優先度 | 中 |

## 概要

管理者がバッチ定義に対する実行スケジュールを登録、更新、参照できる機能。

## 機能要件

- バッチスケジュールの一覧を参照できること
- バッチスケジュールIDを指定して詳細を参照できること
- バッチ定義ID、対象エージェントID、Cron式を指定してスケジュールを登録できること
- バッチスケジュールIDを指定して既存スケジュールを更新できること
- 開始日、終了日、休日実行可否、有効状態、優先度を管理できること

## 非機能要件

- バッチスケジュールの参照、登録、更新は管理者権限を持つ利用者に限定すること
- 開始日と終了日の整合性を保持すること
- 優先度は運用で扱える範囲に制限すること
