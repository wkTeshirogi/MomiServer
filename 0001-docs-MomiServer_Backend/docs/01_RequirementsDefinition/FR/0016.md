# トピック管理

| 項目 | 内容 |
| --- | --- |
| 機能ID | FR-0016 |
| カテゴリ | MQTT通信 |
| 優先度 | 中 |

## 概要

MQTTトピックの命名規則・購読設定・管理を行う機能。

## 機能要件

- トピック命名規則（例：`home/{room}/{device_id}/data`）を定義・管理できること
- 新規デバイス登録時に対応するトピックを自動的にサブスクライブすること
- ワイルドカード（`+`・`#`）を用いたトピック購読に対応すること

## 非機能要件

- トピック定義はDB管理とし、再起動不要で反映できること
