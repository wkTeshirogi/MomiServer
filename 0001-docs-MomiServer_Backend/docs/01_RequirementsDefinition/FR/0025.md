# 在庫登録・更新・削除

| 項目 | 内容 |
| --- | --- |
| 機能ID | FR-0025 |
| カテゴリ | 在庫管理 |
| 優先度 | 中 |

## 概要

在庫アイテムの登録・更新・削除を行うCRUD機能。

## 機能要件

- 在庫品目に品名・カテゴリ・単位・メーカー・型番・JANコード・購入URL・品目管理ステータスを登録できること
- 品目管理ステータスとして `有効`、`無効`、`削除` を管理できること
- 在庫品目と実在庫を分けて管理できること
- 実在庫に数量・保管場所・最小在庫数・在庫ステータスを登録できること
- 実在庫の在庫ステータスとして `在庫あり`、`在庫なし`、`在庫注意`、`削除` を管理できること
- 在庫品目および実在庫を更新できること
- 品目の削除操作時は、品目管理ステータスを `削除` に更新すること
- 実在庫の削除操作時は、実在庫の在庫ステータスを `削除` に更新すること
- REST APIおよびUIから操作できること

## 非機能要件

- 在庫数量はトランザクション管理し、同時更新時のデータ整合性を保証すること
