# ログイン / ログアウト

| 項目 | 内容 |
| --- | --- |
| 機能ID | FR-0003 |
| カテゴリ | ユーザー管理 |
| 優先度 | 高 |

## 概要

ユーザーがシステムへの認証（ログイン）および認証解除（ログアウト）を行う機能。

## 機能要件

- ユーザーはメールアドレスとパスワードを用いてログインできること
- ログイン成功時にJWTアクセストークンおよびリフレッシュトークンを発行すること
- ログアウト時にリフレッシュトークンを無効化すること
- パスワードは bcrypt 等の強度の高いハッシュアルゴリズムで保存すること
- 連続ログイン失敗時の一時ロックと、ロック開始時の管理者通知を提供すること

## 非機能要件

- ログイン処理は1秒以内に完了すること
- ログイン試行のログを記録すること（成功・失敗問わず）
