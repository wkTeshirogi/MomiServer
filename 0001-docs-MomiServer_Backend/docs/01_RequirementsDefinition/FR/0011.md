# IoT機器の登録・削除・更新

| 項目 | 内容 |
| --- | --- |
| 機能ID | FR-0011 |
| カテゴリ | IoT管理サービス |
| 優先度 | 高 |

## 概要

IoTデバイスをシステムに登録・更新・削除するCRUD機能。

## 機能要件

- デバイスの登録時にデバイスID・名称・種別・設置場所・接続プロトコルを指定できること
- 登録済みデバイスの情報を更新できること
- デバイスを論理削除できること
- デバイス削除時はマスタ共通方針に従い、物理削除ではなくステータスを削除扱いの状態へ更新すること
- デバイス削除状態を削除専用フラグでは管理しないこと
- 登録・更新・削除操作はREST API（`POST /api/devices`・`PUT /api/devices/{id}`・`DELETE /api/devices/{id}`）で提供すること

## 非機能要件

- デバイスIDはシステム全体でユニークであること
