# 在庫数量管理

| 項目 | 内容 |
| --- | --- |
| 機能ID | FR-0026 |
| カテゴリ | 在庫管理 |
| 優先度 | 中 |

## 概要

在庫数量の増減を管理し、在庫不足アラートを発報する機能。

## 機能要件

- 在庫数量の入庫・出庫・調整操作を記録できること
- 実在庫ごとに現在数量を管理できること
- 在庫数が最小在庫数を下回った場合に実在庫の在庫ステータスを `在庫注意` として扱えること
- 在庫数が0になった場合に実在庫の在庫ステータスを `在庫なし` として扱えること
- 在庫ステータスが `在庫注意` または `在庫なし` の場合に通知対象として扱えること
- 在庫数量の変動履歴を参照できること

## 非機能要件

- 在庫数量は0未満にならないようAPIレベルでガードすること
