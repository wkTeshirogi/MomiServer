# APIログ表示

| 項目 | 内容 |
| --- | --- |
| 機能ID | FR-0040 |
| カテゴリ | ログ管理 |
| 優先度 | 中 |

## 概要

APIへのリクエスト・レスポンスのログをUIで閲覧・検索する機能。

## 機能要件

- エンドポイント・HTTPメソッド・ステータスコード・レスポンスタイムを記録すること
- 期間・エンドポイント・ステータスコードでフィルタリングできること
- 異常なリクエスト（4xx・5xx）を強調表示すること
- APIアクセスごとに外部参照用のリクエストIDを発行すること
- 発生元をWeb、Agent、IoT、Gateway、未認証に分類できること
- 管理者および運用担当者が一覧・詳細を閲覧できること
- APIログ保存失敗によって、本来のAPI応答を失敗させないこと
- 保持期間を過ぎたAPIログを定期削除すること

## 非機能要件

- ログにはリクエストボディの機微情報（パスワード等）を含めないこと
- Authorization、Cookie、APIキー、レスポンス本文、未加工のクエリ文字列を保存しないこと
- APIログのデフォルト保持期間は30日とすること

## 権限

| ロール | 利用可否 |
| --- | --- |
| ADMIN | 利用可能 |
| OPERATOR | 利用可能 |
| USER | 利用不可 |
| BAN_USER | 利用不可 |
