# 通知条件設定

| 項目 | 内容 |
| --- | --- |
| 機能ID | FR-0042 |
| カテゴリ | 監視設定UI |
| 優先度 | 中 |

## 概要

通知を送信する条件（閾値・頻度・対象チャンネル）をUIから設定する機能。

## 機能要件

- 通知の送信条件（閾値超過・特定イベント発生）を設定できること
- 通知先チャンネル（Discord・メール等）を選択できること
- 同一アラートの通知間隔（クールダウン）を設定できること

## 非機能要件

- 設定UIは直感的に操作でき、エラー時は分かりやすいメッセージを表示すること
