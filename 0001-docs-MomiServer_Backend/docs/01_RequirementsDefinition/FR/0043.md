# Discord通知送信

| 項目 | 内容 |
| --- | --- |
| 機能ID | FR-0043 |
| カテゴリ | 通知機能 |
| 優先度 | 高 |

## 概要

監視アラートやシステムイベントをDiscordのWebhook経由で通知する機能。

## 機能要件

- DiscordのWebhook URLを設定し、メッセージを送信できること
- 通知メッセージにはイベント種別・重要度・発生日時・詳細を含めること
- Embedフォーマットで通知を構造化して送信できること

## 非機能要件

- 送信失敗時は最大3回リトライすること
- リトライ失敗時はエラーログに記録すること
