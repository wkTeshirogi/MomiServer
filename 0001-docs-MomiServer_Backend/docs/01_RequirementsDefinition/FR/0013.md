# デバイス状態管理

| 項目 | 内容 |
| --- | --- |
| 機能ID | FR-0013 |
| カテゴリ | IoT管理サービス |
| 優先度 | 高 |

## 概要

各IoTデバイスのオンライン・オフライン・エラーなどの状態をリアルタイムで管理する機能。

## 機能要件

- デバイスの状態（ONLINE・OFFLINE・ERROR・UNKNOWN）をリアルタイムで管理すること
- 状態変化時にWebSocketまたはイベントとして通知できること
- 最終通信時刻から一定時間（設定可能）経過したデバイスをOFFLINEとして扱うこと

## 非機能要件

- 状態更新の遅延は5秒以内とすること
