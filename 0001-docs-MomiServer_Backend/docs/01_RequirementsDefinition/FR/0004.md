# JWTトークン発行

| 項目 | 内容 |
| --- | --- |
| 機能ID | FR-0004 |
| カテゴリ | ユーザー管理 |
| 優先度 | 高 |

## 概要

認証成功後にJWT形式のアクセストークンおよびリフレッシュトークンを発行する機能。

## 機能要件

- アクセストークンとリフレッシュトークンの有効期限は`application.yaml`で管理すること
- 初期値と設定反映の仕様は[2026/10/26の決定記録](../../90_MeetingMinutesAndNotes/weekly_document_progress_20261026.md)に従うこと
- トークンのペイロードにはユーザーID・ロール・発行日時・有効期限を含めること
- リフレッシュトークンを用いてアクセストークンを再発行できること
- トークンの署名アルゴリズムはHS256またはRS256を使用すること

## 非機能要件

- 秘密鍵はCI/CD変数またはVaultで管理し、コードに含めないこと

## 方針見直し

2026/10/26に、現行値を引き継いで`application.yaml`だけで期限を管理し、共通設定画面は参照専用とする方針を確定した。
従来の固定値「アクセストークン15分・リフレッシュトークン7日」は現行の決定へ置き換える。
これは文書上の方針整理であり、既存トークンの有効期限や実装をこの文書更新で変更するものではない。
