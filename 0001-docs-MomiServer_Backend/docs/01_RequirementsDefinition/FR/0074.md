# バッチ実行ファイルダウンロード

> 状態: 旧API案・未実装。以下の使い切りUUIDによるダウンロード・完了通知は現行APIでは提供していない。
> 再設計時にはAgent専用Bearerと対象ファイルの端末・登録世代の認可を適用する。

## 機能ID

FR-0074

## 機能名

バッチ実行ファイルダウンロード

## 概要

Agent がバッチ実行に必要な入力ファイル、実行スクリプト、設定ファイルなどを Momi Server からダウンロードできるようにする。
ダウンロード URL には事前連携された UUID を使用し、UUID は使い切りとして扱う。

ダウンロード対象ファイルは、ユーザーがバッチ定義マスタで事前登録した配布ファイルを親データとする。
バッチ実行要求作成後、親データから実行要求単位の転送データを作成し、ダウンロード UUID を発行する。

## 関連サービス

- バッチ管理
- Agent 連携
- ファイル管理

## 詳細要件

### 1. UUID指定ダウンロード

#### 詳細説明

Agent は事前に連携されたダウンロード UUID を使用して `/download/{uuid}` 形式でファイルを取得できること。
ファイル形式、ファイル名、サイズ、ハッシュ値はダウンロード前にメタ情報として Agent へ連携する。

#### 入力項目

| 項目名 | 必須 | 内容 |
| --- | --- | --- |
| download_uuid | 必須 | ダウンロード用の使い切り UUID |
| file_name | 必須 | Agent 保存時のファイル名 |
| file_extension | 任意 | ファイル拡張子 |
| content_type | 任意 | ファイルの Content-Type |
| file_size | 任意 | ファイルサイズ |
| checksum_sha256 | 任意 | ファイル内容の SHA-256 |

#### 処理内容

- ダウンロード UUID の有効性を検証する。
- Agent がファイル本体を取得する。
- Agent は取得後にハッシュ値を検証する。
- Agent は成功時に完了通知、失敗時に失敗通知を送信する。
- サーバーは完了通知後に UUID を消費済みにし、次回用 UUID を再生成する。

#### 正常系

- Agent は対象ファイルを取得できる。
- Agent の完了通知後、使用済み UUID は再利用できない。
- 次回ダウンロード用の UUID が再生成される。

#### 異常系

| 条件 | 動作 |
| --- | --- |
| UUID が存在しない | リソース未検出エラーとして扱う |
| UUID が消費済み | リソース未検出または期限切れとして扱う |
| ファイル取得後の検証に失敗した | Agent が失敗通知を送信する |
| 完了通知が来ない | 一定時間後にダウンロード失敗または期限切れとして扱う |

## API仕様

| 項目 | 内容 |
| --- | --- |
| Method | GET |
| Path | `/api/v1/agent/download/{downloadUuid}` |
| 認証 | 旧案: Gateway APIキー。現行方式では不可、再設計が必要 |

## 非機能要件

| 項目 | 内容 |
| --- | --- |
| セキュリティ | UUID は使い切りとし、Agent 認証と紐づき検証を行う |
| 可用性 | 通信失敗時は失敗通知またはタイムアウトにより再発行できる |
| 監査 | ダウンロード開始、完了、失敗、UUID 再生成を記録する |

## 備考

- ダウンロード完了判定は Agent からの完了通知で行う。
- UUID はバッチ定義配布ファイルの固定 ID ではなく、実行要求単位の取得用トークンとして扱う。
