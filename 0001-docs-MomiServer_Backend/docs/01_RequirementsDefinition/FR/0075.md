# バッチ定義配布ファイル管理

## 機能ID

FR-0075

## 機能名

バッチ定義配布ファイル管理

## 概要

ユーザーがバッチ実行に必要なスクリプト、入力ファイル、設定ファイルなどをバッチ定義マスタ内で登録できるようにする。
登録されたファイルはバッチ実行要求作成時に実行単位の転送ファイルとして展開し、Agent がダウンロードできる状態にする。

## 関連サービス

- バッチ管理
- ファイル管理
- Agent 連携

## 詳細要件

### 1. バッチ定義への配布ファイル登録

#### 詳細説明

ユーザーはバッチ定義マスタの登録・更新画面で、Agent に配布するファイルを事前登録できること。
配布ファイル専用の画面は設けない。

#### 入力項目

| 項目名 | 必須 | 内容 |
| --- | --- | --- |
| batch_definition_id | 必須 | 紐づくバッチ定義 ID |
| file_name | 必須 | Agent へ配布するファイル名 |
| file_category | 必須 | `input`、`script`、`agent_update` などのファイルカテゴリ |
| content_type | 任意 | Content-Type |
| checksum_sha256 | 自動 | ファイル内容の SHA-256 |
| file | 必須 | 登録対象ファイル |
| status | 必須 | `active`、`inactive`、`deleted` |

#### 処理内容

- ファイル本体をサーバー側ストレージへ保存する。
- ファイルサイズと SHA-256 を算出する。
- ファイルメタ情報をバッチ定義に紐づく親データとして登録する。
- 削除は物理削除ではなくステータスで管理する。

#### 正常系

- 登録したファイルをバッチ実行時の配布対象として利用できる。
- 同一ファイルを複数のバッチ実行要求で再利用できる。

#### 異常系

| 条件 | 動作 |
| --- | --- |
| 未対応カテゴリが指定された | 入力エラーとして扱う |
| ファイル保存に失敗した | 登録失敗として扱う |
| 削除済みファイルが配布対象に指定された | 入力エラーとして扱う |

## API仕様

| 項目 | 内容 |
| --- | --- |
| Method | POST |
| Path | `/api/master/batch/register` |
| 認証 | JWT Bearer認証 |

## 非機能要件

| 項目 | 内容 |
| --- | --- |
| セキュリティ | 登録・更新は管理者権限を持つユーザーに限定する |
| 可用性 | バッチ定義に紐づく登録済みファイルから、実行要求単位の転送データを生成する |
| 監査 | 登録者、登録日時、更新日時、ステータスを記録する |

## 備考

- 本機能は専用画面を持たず、バッチ定義マスタ管理の一部として扱う。
- 本機能はバッチ実行要求に依存しない、バッチ定義配下の親データを管理する。
- 実行要求作成後の Agent 配布用 UUID は `t_batch_transfer_files` で管理する。
