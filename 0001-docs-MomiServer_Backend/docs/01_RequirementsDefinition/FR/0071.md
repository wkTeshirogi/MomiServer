# バッチ定義管理

| 項目 | 内容 |
| --- | --- |
| 機能ID | FR-0071 |
| カテゴリ | バッチ管理 |
| 優先度 | 中 |

## 概要

管理者がバッチ処理の定義情報を登録、更新、参照できる機能。

## 機能要件

- バッチ定義の一覧を参照できること
- バッチ定義IDを指定して詳細を参照できること
- バッチ定義を新規登録できること
- バッチ定義IDを指定して既存定義を更新できること
- バッチ名、表示名、カテゴリ、実行種別、実行コマンド、ログ出力先を管理できること
- タイムアウト、リトライ回数、リトライ間隔、優先度、並列実行可否を管理できること
- 成功時通知、失敗時通知、ログ保持期限を管理できること

## 非機能要件

- バッチ定義の参照、登録、更新は管理者権限を持つ利用者に限定すること
- 優先度やリトライ回数など、運用上の上限値を入力検証すること
