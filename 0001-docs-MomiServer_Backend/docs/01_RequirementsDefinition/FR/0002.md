# ユーザー情報の参照

| 項目 | 内容 |
| --- | --- |
| 機能ID | FR-0002 |
| カテゴリ | ユーザー管理 |
| 優先度 | 高 |

## 概要

認証済みユーザーが自身のプロフィール情報、およびロールに応じて他ユーザーの情報を参照できる機能。

## 機能要件

- ログイン中のユーザーは自身のユーザー情報（ユーザー名・メールアドレス・ロール・登録日時）を参照できること
- 管理者ロールを持つユーザーはすべてのユーザー情報を一覧・詳細参照できること
- ユーザー情報はREST APIエンドポイント（`GET /api/users/me`、`GET /api/users/{id}`）経由で取得できること

## 非機能要件

- レスポンスタイムは95パーセンタイルで500ms以内とする
- 他ユーザーの情報参照は適切なロールチェックを行い、不正アクセスを防止すること

## 本人向け個人設定

2026/10/24、未実装だったユーザー設定画面の初期範囲を次の3項目として実装した。

| 項目 | 要件 |
| --- | --- |
| ユーザー名 | 本人の表示名を参照・変更する。ログインに使用するメールアドレスとは分離 |
| パスワード | 現在のパスワードを確認して変更し、全セッションを失効して再ログイン |
| テーマ | ライト・ダークを即時反映し、ユーザー単位で保存。ログイン・再読込時に復元 |

ADMIN・OPERATOR・USERが本人の設定のみ変更できる。通知設定、メールアドレス、ロール、他ユーザーの変更は対象外。
既存の管理者用設定変更APIとは分離する。ユーザー名が未設定の既存ユーザーも引き続きログインできる。
