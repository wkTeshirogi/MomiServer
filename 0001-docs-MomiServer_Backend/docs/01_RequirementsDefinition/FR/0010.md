# スコープ設定（アクセス範囲制御）

| 項目 | 内容 |
| --- | --- |
| 機能ID | FR-0010 |
| カテゴリ | ユーザー管理 |
| 優先度 | 中 |

## 概要

APIキーに対してアクセス可能なリソース・操作範囲（スコープ）を設定する機能。

## 機能要件

- Phase 1は`inventory:read`と`inventory:write`を指定できること
- `inventory:write`は既存在庫への入庫・出庫・棚卸をすべて許可し、参照スコープを暗黙付与しないこと
- Phase 1では品目・保管場所ごとのアクセス制限を追加せず、公開対象在庫を操作対象とすること
- スコープ外のエンドポイントへのアクセスは403エラーを返すこと
- Phase 1では発行後のスコープ変更は提供せず、権限変更は新規発行と旧キー無効化で行うこと
- キー発行者のWebロールを外部APIの権限へ引き継がないこと
- 車庫管理はPhase 1対象外とし、将来の専用スコープを既存キーへ自動付与しないこと

## 非機能要件

- スコープ定義はシステム全体で統一した命名規則に従うこと
