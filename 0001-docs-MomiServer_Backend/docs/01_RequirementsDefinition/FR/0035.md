# CPU / メモリ / ディスク監視

| 項目 | 内容 |
| --- | --- |
| 機能ID | FR-0035 |
| カテゴリ | リソース監視 |
| 優先度 | 高 |

## 概要

サーバーのCPU使用率・メモリ使用率・ディスク使用率を継続的に監視する機能。

## 機能要件

- CPU・メモリ・ディスクの使用率をリアルタイムで収集・表示すること
- 各指標に閾値（警告・危険）を設定し、超過時に通知を発報すること
- 収集データを時系列で保存しグラフ表示できること

## 非機能要件

- メトリクス収集間隔はデフォルト60秒とし、設定で変更可能とすること
