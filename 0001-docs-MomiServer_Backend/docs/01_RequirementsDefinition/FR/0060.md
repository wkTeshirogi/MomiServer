# Discord bot情報取得

| 項目 | 内容 |
| --- | --- |
| 機能ID | FR-0060 |
| カテゴリ | 外部情報連携 |
| 優先度 | 低 |

## 概要

Discord BotのAPIを利用してサーバーや参加メンバーの情報を取得する機能。

## 機能要件

- Discord Bot Token を使用してGuild情報・オンラインメンバー数を取得できること
- 取得情報をダッシュボードに表示できること
- Bot Tokenは環境変数で管理し、コードに含めないこと

## 非機能要件

- Discord APIのレートリミットを考慮したリクエスト制御を行うこと
