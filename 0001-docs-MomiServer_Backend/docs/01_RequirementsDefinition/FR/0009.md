# APIキーの無効化

| 項目 | 内容 |
| --- | --- |
| 機能ID | FR-0009 |
| カテゴリ | ユーザー管理 |
| 優先度 | 中 |

## 概要

発行済み外部APIキーをADMINが無効化する機能。

## 機能要件

- ADMINはすべての外部APIキーを無効化できること
- 無効化はステータス更新で実施し、再有効化と物理削除は提供しないこと
- 無効化の確認画面にキー名・識別用プレフィックス・最終利用日時を表示すること
- 無効化されたAPIキーによるアクセスは即時に401エラーを返すこと
- 無効化履歴には操作者・日時・対象キーを記録し、キー原文は含めないこと

## 実装状況

2026/10/24に確認モーダルへの識別用プレフィックス・最終利用日時の表示を追加した。
最終利用日時が未記録の場合は「未利用」と表示する。キャンセル時は無効化要求を送信しない。

## 非機能要件

- 無効化のトランザクション確定後、新しく認証する要求から拒否すること。処理中の要求は取り消さない
