# MQTTブローカーとの接続

| 項目 | 内容 |
| --- | --- |
| 機能ID | FR-0014 |
| カテゴリ | MQTT通信 |
| 優先度 | 高 |

## 概要

Spring Boot BackendがMQTTブローカーと接続し、メッセージの送受信を行うための接続管理機能。

## 機能要件

- MQTTブローカー（Mosquittoなど）へのTCP/TLS接続を確立できること
- 接続断時に自動再接続すること（バックオフ付き）
- 接続設定（ホスト・ポート・認証情報）は環境変数で管理すること

## 非機能要件

- 再接続試行は最大10回、指数バックオフ（最大60秒）で行うこと
