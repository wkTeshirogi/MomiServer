# ロールベースアクセス制御（RBAC）

| 項目 | 内容 |
| --- | --- |
| 機能ID | FR-0006 |
| カテゴリ | ユーザー管理 |
| 優先度 | 高 |

## 概要

ユーザーに割り当てたロールに基づいてAPIエンドポイントや機能へのアクセスを制御する機能。

## 機能要件

- システムは`ADMIN`・`USER`・`VIEWER`の3種類以上のロールを持つこと
- 各APIエンドポイントにアクセス可能なロールを定義できること
- ユーザーには複数ロールを付与できること
- ロールの付与・剥奪は管理者のみ実施できること

## 非機能要件

- ロール定義はコード変更なしに設定ファイルまたはDBで管理できること
