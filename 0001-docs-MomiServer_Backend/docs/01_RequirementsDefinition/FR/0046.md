# 重要度別通知制御

| 項目 | 内容 |
| --- | --- |
| 機能ID | FR-0046 |
| カテゴリ | 通知ルール |
| 優先度 | 中 |

## 概要

通知の重要度（INFO・WARNING・CRITICAL）に応じて送信先・送信方式を制御する機能。

## 機能要件

- 重要度を`INFO`・`WARNING`・`CRITICAL`の3段階で定義すること
- 重要度ごとに通知先チャンネルを設定できること
- `CRITICAL`は即時送信、`INFO`はバッチ送信など送信タイミングを重要度で制御できること

## 非機能要件

- `CRITICAL`通知は発生から1分以内に送信されること
