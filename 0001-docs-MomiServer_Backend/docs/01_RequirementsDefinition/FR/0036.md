# ヘルスチェックAPI提供

| 項目 | 内容 |
| --- | --- |
| 機能ID | FR-0036 |
| カテゴリ | ヘルスチェック |
| 優先度 | 高 |

## 概要

各サービスの正常性を外部から確認するためのヘルスチェックエンドポイントを提供する機能。

## 機能要件

- `GET /actuator/health`（Spring Boot）または`GET /health`でサービスの状態を返すこと
- レスポンスにはDB接続・MQTTブローカー接続・外部API接続の状態を含めること
- 正常時は200、異常時は503を返すこと

## 非機能要件

- ヘルスチェックのレスポンスは500ms以内とすること
