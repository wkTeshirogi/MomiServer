# データ受信・保存

| 項目 | 内容 |
| --- | --- |
| 機能ID | FR-0017 |
| カテゴリ | センサーデータ管理 |
| 優先度 | 高 |

## 概要

IoTデバイスから送信されたセンサーデータを受信し、DBへ保存する機能。

## 機能要件

- MQTT・HTTPの両経路でセンサーデータを受信できること
- 受信データを受信日時・デバイスID・データ種別・値とともにDBへ保存すること
- データ形式はJSON（例：`{"device_id":"xxx","type":"temperature","value":22.5}`）とすること
- バリデーションエラーのデータはエラーログに記録し、スキップすること

## 非機能要件

- 1秒間に100件以上のデータを処理できること
