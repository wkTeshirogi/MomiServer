# NFR-0028: メッセージロスト防止

| 項目 | 内容 |
| --- | --- |
| 要件ID | NFR-0028 |
| カテゴリ | イベント基盤 |
| 優先度 | 高 |
| 要件種別 | 信頼性 |

## 概要

システム障害・再起動時でもイベントメッセージが失われないよう永続化・確認応答を行う要件。

## 要件

- イベントはディスクに永続化し、プロセス再起動後も消失しないこと
- コンシューマーは処理完了後にACKを送信し、未ACKメッセージを再配信すること
- プロデューサーはブローカーからのACKを受信するまで送信完了とみなさないこと
- メッセージの配信保証レベル（At-least-once / Exactly-once）を設計で明示すること

## 関連機能要件

`MQTT-002`, `NFR-0006`
