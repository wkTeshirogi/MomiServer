# NFR-0002: JWTの有効期限管理

| 項目 | 内容 |
| --- | --- |
| 要件ID | NFR-0002 |
| カテゴリ | ユーザー管理 |
| 優先度 | 高 |
| 要件種別 | セキュリティ |

## 概要

発行したJWTトークンの有効期限を適切に管理し、期限切れトークンによる不正アクセスを防止する要件。

## 要件

- アクセストークンの有効期限は15分以内とすること
- リフレッシュトークンの有効期限は7日以内とすること
- 有効期限切れトークンは401エラーを返しアクセスを拒否すること
- リフレッシュトークンのローテーション（使用済み無効化）を実装すること
- トークンの有効期限は環境変数で設定可能とすること
