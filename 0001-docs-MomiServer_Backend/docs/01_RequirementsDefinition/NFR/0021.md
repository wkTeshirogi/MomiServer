# NFR-0021: 配信失敗時のリトライ処理

| 項目 | 内容 |
| --- | --- |
| 要件ID | NFR-0021 |
| カテゴリ | 通知ルール |
| 優先度 | 高 |
| 要件種別 | 信頼性 |

## 概要

Discord等の通知チャンネルへの送信が失敗した場合に、リトライを行って確実に配信する要件。

## 要件

- 送信失敗時は最大3回のリトライを行うこと
- リトライは指数バックオフ（初回5秒・最大2分）で行うこと
- 全リトライ失敗時はエラーログに記録し、管理者へ二次通知すること
- リトライ状況（試行回数・最終エラー）を通知履歴に保存すること

## 関連機能要件

`NOTIF-001`, `NOTIF-002`
