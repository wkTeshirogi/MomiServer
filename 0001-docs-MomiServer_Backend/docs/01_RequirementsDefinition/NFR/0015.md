# NFR-0015: 履歴データの保持

| 項目 | 内容 |
| --- | --- |
| 要件ID | NFR-0015 |
| カテゴリ | AI連携 |
| 優先度 | 中 |
| 要件種別 | データ管理 |

## 概要

AI推論の入力データおよび推論結果を履歴として保持し、精度検証・再学習に活用できる要件。

## 要件

- AI推論の入力データ・推論結果・実行日時を履歴テーブルに保存すること
- 履歴データの保持期間は設定可能（デフォルト：180日）とすること
- 保持期間を超えたデータは自動的にアーカイブまたは削除すること
- 履歴データはAPI経由で取得できること
