# NFR-0013: データ整合性保証（在庫数の正確性）

| 項目 | 内容 |
| --- | --- |
| 要件ID | NFR-0013 |
| カテゴリ | AI連携 |
| 優先度 | 高 |
| 要件種別 | データ整合性 |

## 概要

AI推論結果を在庫数へ反映する際に、データの整合性を保証して正確な在庫数を維持する要件。

## 要件

- AI推論結果による在庫数更新はトランザクション内で行うこと
- 在庫数は0未満にならないようアプリケーション・DBの両レベルで制約を設けること
- 更新前後の在庫数を変動履歴テーブルに記録すること
- AI推論による更新と手動更新が競合した場合の解決ルールを定義すること

## 関連機能要件

`INV-002`, `AI-001`
