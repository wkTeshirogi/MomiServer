# NFR-0023: 推論レスポンス時間制御

| 項目 | 内容 |
| --- | --- |
| 要件ID | NFR-0023 |
| カテゴリ | AIエージェント連携 |
| 優先度 | 中 |
| 要件種別 | パフォーマンス |

## 概要

AIモデルの推論処理が一定時間以内に完了するようタイムアウトと時間制御を行う要件。

## 要件

- 推論APIのタイムアウトは30秒とし、超過時は503を返すこと
- 推論リクエストのレスポンスタイムを計測しメトリクスとして記録すること
- 95パーセンタイルのレスポンスタイムが10秒以内であることを目標とすること
- 長時間かかる推論は非同期ジョブ化し、Webhook・ポーリングで結果を返すこと
