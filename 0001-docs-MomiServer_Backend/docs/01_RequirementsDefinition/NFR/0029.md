# NFR-0029: 再送制御

| 項目 | 内容 |
| --- | --- |
| 要件ID | NFR-0029 |
| カテゴリ | イベント基盤 |
| 優先度 | 高 |
| 要件種別 | 信頼性 |

## 概要

処理失敗したイベントを適切に再送し、最終的に処理が完了することを保証する要件。

## 要件

- 処理失敗イベントはデッドレターキュー（DLQ）に移送し、後から再処理できること
- 再送は指数バックオフ（最大リトライ回数は設定可能）で行うこと
- 最大リトライ回数超過後はDLQに格納し、管理者へ通知すること
- 再送処理の状況（試行回数・失敗理由）をログに記録すること
- DLQに溜まったメッセージを管理UIから確認・手動再処理できること

## 関連機能要件

`NFR-0021`, `NFR-0028`, `TRIG-001`
