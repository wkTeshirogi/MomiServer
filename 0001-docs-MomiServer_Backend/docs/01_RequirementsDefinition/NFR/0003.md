# NFR-0003: APIキーのレート制限対応

| 項目 | 内容 |
| --- | --- |
| 要件ID | NFR-0003 |
| カテゴリ | ユーザー管理 |
| 優先度 | 中 |
| 要件種別 | 可用性 / セキュリティ |

## 概要

APIキーを用いたリクエストに対してレート制限を設け、過剰アクセスやDOS攻撃からシステムを保護する要件。

## 要件

- APIキー単位でリクエスト数を制限できること（デフォルト：1000回/時）
- 制限超過時は429（Too Many Requests）を返すこと
- レスポンスヘッダーに残りリクエスト数（X-RateLimit-Remaining）とリセット時刻を含めること
- Phase 1の外部APIはキーごとに1000回/時の固定上限とし、カウンターをDBで共有すること
- スコープ別・キー別上限の変更画面は将来対応とすること
