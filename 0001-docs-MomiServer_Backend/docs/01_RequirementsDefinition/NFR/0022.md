# NFR-0022: 非同期処理（キュー利用）

| 項目 | 内容 |
| --- | --- |
| 要件ID | NFR-0022 |
| カテゴリ | 通知ルール |
| 優先度 | 中 |
| 要件種別 | パフォーマンス / 信頼性 |

## 概要

通知送信処理をメインの処理フローから切り離し、キューを介して非同期で実行する要件。

## 要件

- 通知送信はメッセージキュー（RabbitMQ・Redis Streams等）を介して非同期で処理すること
- キューへの積み込みは5ms以内に完了し、メイン処理をブロックしないこと
- キューのデッドレターキューを設定し、処理失敗メッセージを保持すること
- キューの深さ・処理速度をメトリクスとして監視すること

## 関連機能要件

`NOTIF-001`, `NOTIF-002`, `NOTIF-003`
