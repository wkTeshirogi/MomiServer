# NFR-0020: 通知重複防止（冪等性）

| 項目 | 内容 |
| --- | --- |
| 要件ID | NFR-0020 |
| カテゴリ | 通知ルール |
| 優先度 | 高 |
| 要件種別 | 信頼性 |

## 概要

同一イベントに対して通知が重複して送信されないよう冪等性を保証する要件。

## 要件

- 同一イベントIDに対する通知は1回のみ送信すること
- 通知送信前にイベントIDをキー（Redis等）として重複チェックを行うこと
- クールダウン期間（デフォルト5分）内の同一アラートは再通知しないこと
- 重複防止ロジックをバイパスできる強制送信オプションを管理者向けに提供すること

## 関連機能要件

`NOTIF-001`, `NOTIF-002`, `NRULE-001`
