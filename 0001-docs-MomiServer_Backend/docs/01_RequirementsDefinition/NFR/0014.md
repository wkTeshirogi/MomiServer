# NFR-0014: 同時更新時の競合制御

| 項目 | 内容 |
| --- | --- |
| 要件ID | NFR-0014 |
| カテゴリ | AI連携 |
| 優先度 | 中 |
| 要件種別 | データ整合性 |

## 概要

複数のプロセスやユーザーが同時に同一データを更新する場合の競合を制御する要件。

## 要件

- 楽観的ロック（バージョン番号またはタイムスタンプ）を用いて競合を検出すること
- 競合検出時はクライアントへ409（Conflict）を返し、再試行を促すこと
- 高頻度更新が予想されるデータには悲観的ロックを検討すること
- 競合発生件数をメトリクスとして記録すること
