# NFR-0025: GPU/CPUリソース分離

| 項目 | 内容 |
| --- | --- |
| 要件ID | NFR-0025 |
| カテゴリ | AIエージェント連携 |
| 優先度 | 低 |
| 要件種別 | パフォーマンス / 信頼性 |

## 概要

AI推論処理が他のサービスのリソースを圧迫しないよう、計算リソースを分離する要件。

## 要件

- AI推論サービスは他のバックエンドサービスと独立したプロセス・コンテナで動作すること
- CPUリソース上限をコンテナレベルで設定すること（例：最大4コア）
- GPU利用可能な環境では推論処理をGPUにオフロードすること
- リソース使用率を監視し、上限に近づいた場合にアラートを発報すること

## 関連機能要件

`AI-001`, `AI-002`, `RES-001`
