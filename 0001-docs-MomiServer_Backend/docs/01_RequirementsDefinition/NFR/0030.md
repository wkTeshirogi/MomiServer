# 認証セッション管理

| 項目 | 内容 |
| --- | --- |
| 要件ID | NFR-0030 |
| カテゴリ | 認証 |
| 優先度 | 高 |

## 概要

リフレッシュトークンをサーバ側セッションとして管理し、トークン更新、ログアウト、失効判定を安全に行う。

## 非機能要件

- リフレッシュトークンはハッシュ化して保存すること
- トークン更新時に同一セッションのリフレッシュトークンをローテーションすること
- ログアウト時に指定されたセッションを失効できること
- 失効済み、期限切れ、ユーザー不一致のリフレッシュトークンを拒否すること
- ユーザー削除時に関連セッションも削除されること
