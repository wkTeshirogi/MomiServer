# NFR-0011: 実行失敗時のリトライ機構

| 項目 | 内容 |
| --- | --- |
| 要件ID | NFR-0011 |
| カテゴリ | タスク管理 |
| 優先度 | 高 |
| 要件種別 | 信頼性 |

## 概要

タスクやジョブの実行が失敗した際に、自動的にリトライを行い処理を完了させる要件。

## 要件

- タスク実行失敗時に最大3回のリトライを行うこと
- リトライは指数バックオフ（初回30秒・最大10分）で行うこと
- 最大リトライ回数を超えた場合は`FAILED`状態として記録し、管理者に通知すること
- リトライ回数・最終失敗理由をタスク履歴に記録すること

## 関連機能要件

`TASK-001`, `TASK-002`, `SCHED-001`
