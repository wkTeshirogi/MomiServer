# NFR-0006: オフラインデータの再送処理

| 項目 | 内容 |
| --- | --- |
| 要件ID | NFR-0006 |
| カテゴリ | MQTT通信 |
| 優先度 | 高 |
| 要件種別 | 信頼性 |

## 概要

MQTT接続断中にデバイス側で蓄積されたデータを、再接続後に確実に受信・処理する要件。

## 要件

- QoS 1以上を使用してメッセージの到達を保証すること
- ブローカーのPersistent Session（CleanSession=false）を利用してオフライン中メッセージを保持すること
- 再接続後にオフライン中に蓄積されたメッセージを順序通りに処理すること
- 再送メッセージの重複処理を防ぐ冪等性制御を実装すること

## 関連機能要件

`MQTT-001`, `MQTT-002`
