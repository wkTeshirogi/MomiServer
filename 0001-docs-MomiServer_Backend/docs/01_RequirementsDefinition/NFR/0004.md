# NFR-0004: 不正アクセスログの記録

| 項目 | 内容 |
| --- | --- |
| 要件ID | NFR-0004 |
| カテゴリ | ユーザー管理 |
| 優先度 | 高 |
| 要件種別 | セキュリティ / 監査 |

## 概要

ログイン失敗・権限エラー・無効トークンなどの不正アクセス試行を記録し、インシデント対応に備える要件。

## 要件

- ログイン失敗・連続失敗・アカウントロックのイベントをログに記録すること
- 無効トークン・期限切れトークンによるアクセス試行を記録すること
- ログには日時・IPアドレス・ユーザーID・エンドポイント・失敗理由を含めること
- 不正アクセスが閾値を超えた場合に管理者へ通知すること
- ログは改ざん防止のため書き込み専用ストレージに保存すること

## 関連機能要件

`USR-002`, `USR-004`, `LOG-001`
