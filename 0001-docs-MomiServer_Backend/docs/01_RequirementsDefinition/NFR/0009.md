# NFR-0009: Cronジョブの冪等性保証

| 項目 | 内容 |
| --- | --- |
| 要件ID | NFR-0009 |
| カテゴリ | タスク管理 |
| 優先度 | 高 |
| 要件種別 | 信頼性 |

## 概要

Cronジョブが複数回実行された場合でも、処理結果が同一になるよう冪等性を保証する要件。

## 要件

- 同一ジョブが重複実行された場合に副作用が生じないよう実装すること
- 処理済みデータにはフラグまたはタイムスタンプを付与して二重処理を防止すること
- DBへの書き込みはUPSERT（INSERT OR UPDATE）を使用すること
- 冪等性の検証テストをCIパイプラインに含めること

## 関連機能要件

`SCHED-002`, `TASK-001`
