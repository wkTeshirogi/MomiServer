# NFR-0001: パスワードはハッシュ化して保存（bcrypt等）

| 項目 | 内容 |
| --- | --- |
| 要件ID | NFR-0001 |
| カテゴリ | ユーザー管理 |
| 優先度 | 高 |
| 要件種別 | セキュリティ |

## 概要

ユーザーのパスワードを平文で保存せず、強度の高いハッシュアルゴリズムを用いて安全に保存する要件。

## 要件

- パスワードはbcrypt（コストファクター12以上）またはArgon2idを使用してハッシュ化すること
- 平文パスワードはいかなるログ・DBにも保存しないこと
- パスワード変更時は旧ハッシュを即時無効化すること
- ハッシュアルゴリズムは設定で変更可能とし、移行パスを設けること

## 関連機能要件

`USR-002`, `USR-003`
