# NFR-0007: デバイスIDの一意性保証

| 項目 | 内容 |
| --- | --- |
| 要件ID | NFR-0007 |
| カテゴリ | MQTT通信 |
| 優先度 | 高 |
| 要件種別 | データ整合性 |

## 概要

システムに登録されるIoTデバイスのIDがシステム全体で一意であることを保証する要件。

## 要件

- デバイスIDはUUID v4またはシステム生成の一意な文字列とすること
- デバイス登録時にDBレベルでユニーク制約を設けること
- MQTTクライアントIDにデバイスIDを使用し、重複接続を防止すること
- 削除済みデバイスのIDは一定期間（90日）再利用しないこと

## 関連機能要件

`IOT-001`, `MQTT-001`
