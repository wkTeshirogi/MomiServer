# NFR-0016: ログの高速検索性

| 項目 | 内容 |
| --- | --- |
| 要件ID | NFR-0016 |
| カテゴリ | ログ管理 |
| 優先度 | 中 |
| 要件種別 | パフォーマンス |

## 概要

大量のログデータから目的のログを高速に検索・取得できる要件。

## 要件

- ログ検索（期間・キーワード・ログレベル）が10秒以内に完了すること
- ログストレージには全文検索に対応したElasticsearch等を採用すること
- 頻繁に検索されるフィールド（日時・ログレベル・サービス名）にインデックスを設定すること
- 検索クエリの実行時間をモニタリングし、閾値超過時にアラートを発報すること

## 関連機能要件

`LOG-001`, `LOG-002`, `LOG-003`
