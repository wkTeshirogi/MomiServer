# NFR-0027: 高スループット対応

| 項目 | 内容 |
| --- | --- |
| 要件ID | NFR-0027 |
| カテゴリ | イベント基盤 |
| 優先度 | 高 |
| 要件種別 | パフォーマンス |

## 概要

システム内で発生する大量のイベントを遅延なく処理できるイベント基盤の要件。

## 要件

- 1秒間に1000件以上のイベントを処理できること
- イベントバスにはKafka・RabbitMQ・Redis Streams等の高スループット対応のミドルウェアを使用すること
- コンシューマーをスケールアウトできるパーティション・コンシューマーグループ構成とすること
- スループットをリアルタイムで監視し、限界値の80%到達時にアラートを発報すること

## 関連機能要件

`MQTT-002`, `TRIG-001`, `NOTIF-002`
