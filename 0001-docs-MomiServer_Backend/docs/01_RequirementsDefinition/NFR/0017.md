# NFR-0017: ログ保持期間の管理

| 項目 | 内容 |
| --- | --- |
| 要件ID | NFR-0017 |
| カテゴリ | ログ管理 |
| 優先度 | 中 |
| 要件種別 | データ管理 |

## 概要

ログデータの保持期間を管理し、ストレージの圧迫を防ぎながら必要な期間のログを保持する要件。

## 要件

- ログ種別（アプリ・IoT・API）ごとに保持期間を個別設定できること
- デフォルトの保持期間はアプリログ30日・IoTログ90日・APIログ30日とすること
- 保持期間を超えたログは自動的に削除またはアーカイブすること
- 削除・アーカイブの実行結果をシステムログに記録すること

## 関連機能要件

`LOG-001`, `LOG-002`, `LOG-003`
