# NFR-0008: 高頻度データ受信への耐性

| 項目 | 内容 |
| --- | --- |
| 要件ID | NFR-0008 |
| カテゴリ | MQTT通信 |
| 優先度 | 高 |
| 要件種別 | パフォーマンス |

## 概要

多数のIoTデバイスから高頻度でデータが送信される状況でも、システムが安定して処理できる要件。

## 要件

- 1秒間に100件以上のMQTTメッセージを処理できること
- 受信処理はノンブロッキング（非同期）で実装すること
- バックプレッシャー制御を実装し、処理キューの溢れを防止すること
- 高負荷時でもメッセージロストが発生しないこと
- スループットと遅延をメトリクスとして記録すること

## 関連機能要件

`MQTT-002`, `SENSOR-001`
