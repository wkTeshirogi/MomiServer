# NFR-0012: 同時実行制御（排他制御）

| 項目 | 内容 |
| --- | --- |
| 要件ID | NFR-0012 |
| カテゴリ | タスク管理 |
| 優先度 | 高 |
| 要件種別 | 信頼性 / データ整合性 |

## 概要

同一タスクやジョブが複数のスレッド・ノードで同時に実行されることを防ぐ排他制御の要件。

## 要件

- 分散ロック（RedisのSETNX等）を用いて同一ジョブの同時実行を防止すること
- ロックの有効期限を設定し、プロセスクラッシュ時のデッドロックを防止すること
- 排他制御の取得失敗時はジョブをスキップし、ログに記録すること
- ロックの取得・解放状況をメトリクスとして記録すること

## 関連機能要件

`SCHED-002`, `TASK-001`
