# NFR-0005: MQTT切断時の再接続処理

| 項目 | 内容 |
| --- | --- |
| 要件ID | NFR-0005 |
| カテゴリ | MQTT通信 |
| 優先度 | 高 |
| 要件種別 | 可用性 |

## 概要

MQTTブローカーとの接続が切断された際に、自動的に再接続を試みてサービスの継続性を保つ要件。

## 要件

- 接続切断を検知後、即座に再接続を試みること
- 再接続は指数バックオフ（初回1秒・最大60秒）で行うこと
- 再接続試行回数の上限を設定できること（デフォルト：無制限）
- 再接続成功時にサブスクライブしていたトピックを自動的に再購読すること
- 再接続の試行・成功・失敗をログに記録すること
