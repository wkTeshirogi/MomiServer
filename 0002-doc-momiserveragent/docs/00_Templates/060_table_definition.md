## マスタ削除制御

マスタデータを通常利用から除外する場合は、物理削除ではなくステータスを削除扱いの状態へ更新する。
削除状態はステータスで管理し、`delete_flag`、`deleted`、`is_deleted` などの削除専用フラグは保持しない。
`enabled` などの有効状態項目は有効 / 無効の切り替えに限定し、削除状態の管理には使用しない。
