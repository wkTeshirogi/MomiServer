# ドキュメントテンプレート

## 概要

本ディレクトリは、既存ドキュメントと同じ粒度で新規ドキュメントを作成するためのテンプレート集です。

## 使い方

1. 作成したいドキュメント種別のテンプレートをコピーする。
2. ファイル名を既存の採番規則に合わせて変更する。
3. `TODO` または `未定` の箇所を対象機能の内容に置き換える。
4. 関連する `000_index.md` にリンクを追加する。
